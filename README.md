# Orange Money Loan Application

A static site loan application for Orange Money (Botswana) with Telegram bot integration.

## Quick Start

```bash
bash setup.sh
yarn dev
```

Visit: http://localhost:3000

## Deployment

### GitHub Pages
1. Settings > Pages
2. Select main branch
3. Live at: https://tererngetich8-del.github.io/orange-loan-app

### Vercel
```bash
vercel
```

### Netlify  
```bash
netlify deploy --prod
```

## Features

- 5-stage loan application flow
- Telegram bot integration
- Orange Money branding
- Responsive design
- OTP verification with countdown

## Colors

- Primary Orange: #FF6600
- Light Orange: #FFE5CC
- Dark Orange: #CC5200
